# ALAM Innovation handoff — 2026-09-04 13:00 JST

- **Lane:** Innovation Agent
- **User problem:** Today already identifies a validated Practical action, but a reader still had to open the article to discover whether that action carried an explicit deadline. On mobile this hides the most time-sensitive part of an otherwise decision-first briefing.
- **Root cause:** `alam_daily_brief.py` surfaced the structured `content.action` decision but ignored the existing v5 Practical `content.deadline` field.
- **Decision:** Show a compact deadline line only for the actionable Today row and only when the published record explicitly contains a usable scalar deadline. Do not parse article prose, calculate urgency, invent countdowns, or reinterpret malformed structured values.
- **Implementation:** Added `_deadline_note()` and rendered `Deadline · <published value>` beneath the action copy in the Today card. Whitespace is normalized for mobile readability; placeholders (`TBD`, `unknown`, `N/A`, etc.), booleans, mappings and lists fail closed to no deadline line. Display is capped at 96 characters. Existing selection/ranking, action labels, Saved-update priority, anti-filter-bubble fallback and CTAs are unchanged.
- **Files affected:** `alam_app/alam_daily_brief.py`, `alam_app/test_alam_daily_brief.py`, this handoff. No schema, RLS, Auth, telemetry, ingestion or public article changes.
- **Mobile behavior:** The deadline sits inside the existing briefing card between the decision copy and lower-priority relevance/lifecycle metadata, so the due condition is visible before the reader taps through. It adds no extra button or horizontal layout.
- **Validation:** Focused regression coverage verifies exact deadline passthrough, whitespace normalization and fail-closed handling for absent/placeholder/structured/boolean values. Pre-change `main` ALAM app checks were green at `7a87a07d72b164d7d770b00b10413214e24d0f41`. Post-change GitHub Actions were running when this handoff was written; do not claim final green until the workflow completes.
- **Live Supabase:** Project `zecztyabmmoqzjumhxxf` reported 59 public articles and 0 Auth users during this run. There is no evidence the external Auth blocker changed, so it was not revisited.
- **Remaining limitation:** The deadline field is intentionally displayed as validated publisher-authored metadata, not normalized into a date. This avoids silently changing semantics such as `while funds last`, `before renewal`, or multi-stage application windows.
- **Recommended next step:** Continue Today/Home product quality by distinguishing explicitly time-bound action items from ordinary actionable items only if the data contract gains a validated machine-readable deadline/urgency contract; until then, keep ranking unchanged rather than inferring urgency from text.
