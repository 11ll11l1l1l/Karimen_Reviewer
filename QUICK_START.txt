KARIMEN REVIEWER v4.4 POLISHED — QUICK START

1. Keep this whole folder structure intact.
2. If using Supabase rankings, keep your existing Streamlit Cloud Secrets.
3. If you never ran the v4.3 Supabase migration, run supabase_setup.sql once in Supabase SQL Editor.
4. Install requirements:

   pip install -r requirements.txt

5. Run locally:

   streamlit run app.py

6. First screen:
   - enter ranking nickname
   - choose player character
   - choose A1+B1, A1 only, or B1 only
   - choose mascot voice/theme

Recommended voice: Natural neural voice (online).
If neural speech cannot be produced, v4.4 stays silent rather than secretly using a robotic device voice. Use Settings > Test selected voice to confirm the backend on your deployment.

Useful checks before deployment:

   python validate.py
   python release_audit.py
   python smoke_test.py
   python runtime_stub_test.py
   python strict_runtime_test.py
   python supabase_stub_test.py
